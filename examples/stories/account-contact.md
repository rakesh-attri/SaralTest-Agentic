# Story SF-DEMO-1: Create a Contact under an Account

As a Sales Rep, I want to create a Contact linked to an existing Account, so that customer contacts are tracked per company.

Acceptance criteria:
1. A Contact can be created from the Account's Contacts related list with First Name, Last Name and Email.
2. Last Name is required; saving without it shows an error.
3. The new Contact's Account is the Account it was created from.
4. A Read-Only user cannot create or edit Contacts.
